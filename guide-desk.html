1. 상담하러 학생·학부모가 오셨을 때

💬 이런 상황 — “중2인데 상담 좀 받으러 왔어요.” / 전화로 “자료 좀 받아볼 수 있을까요?”

인쇄해서 드리는 순서

  1. 🖨️ 상담용 자료 탭을 누릅니다.
  2. 학년을 고릅니다. 중등은 중1·중2·중3, 고등은 학교까지 골라야 합니다(미사고1 / 미사강변고1 / 하남고1 / 미사고2 / 미사강변고2 / 고3).
  3. 포함할 항목이 전부 체크되어 있는지 확인합니다. 필요 없는 것만 눌러서 끕니다.
  4. 🖨️ 전체 인쇄 / PDF 저장 을 누르면 인쇄창이 뜹니다. 그대로 인쇄하시면 됩니다.

무엇이 인쇄되나요

문서이런 내용입니다
① 학원 리플렛다올105 × 대치더올 소개. 학원이 어떤 곳인지 한눈에 보여드리는 자료

③ 수업 방식 안내과목별로 왜 이렇게 가르치는지, 선생님 원칙, 강좌 내용, 사용 교재
④ 강사 프로필·실적그 학년 담당 선생님 사진·이력·주요 성적 우수자
⑤ 전체 성적 우수자학원 전체 명단 (1등급·만점·대학 합격)
⑥ 입시 컨설팅고등 학년을 골랐을 때만 나옵니다. 프로그램·비용·필요 서류
⑦ 학원 사용 설명서수강료·환불·결제·보강·퇴원 규정. 신입생 학부모 필독

주의 — 학년을 잘못 고르면 다른 학년 시간표가 인쇄됩니다. 인쇄 전에 화면 맨 위 학년이 맞는지 한 번만 더 봐 주세요.

인쇄가 흐리게 나오면 — 인쇄창에서 배율은 “기본”, 여백은 “없음” 또는 “최소”로 두세요. 화면 아래에도 같은 안내가 뜹니다. 이 두 개만 맞추면 글씨가 또렷하게 나옵니다.

전학년 한 장으로 보기

🎓 학년별 시간표 맨 왼쪽 🗂 전학년 통합 을 누르면 모든 학년이 한 장에 나옵니다. 세로 = 학년(중1 → 고3), 가로 = 월·수·금 → 화·목·토 순서입니다.
월수금반과 화목토반이 붙어 보이도록 요일을 이 순서로 놓았습니다. 상담 때 “다른 요일반도 있나요?”에 바로 답할 수 있습니다.

「🎨 시간표 생성」의 빨간 박스 · 노란 박스

박스뜻해야 할 일
⚠️ 시간 충돌 N건
빨간 박스		 같은 학년 학생이 동시에 들을 수 없는 수업이 겹쳐 있습니다. 수업 ↔ 수업이 정면으로 부딪힌 경우만 여기 뜹니다. 원장님께 보고하세요. 인포에서 임의로 시간을 옮기지 않습니다.
ℹ️ 참고 N건 — 충돌 아님
노란 박스		 겹치긴 하지만 운영상 문제가 없는 경우입니다. 아래 줄에 사유가 적혀 나옵니다. 아무것도 하지 않으셔도 됩니다. 물어보시면 사유를 그대로 읽어드리면 됩니다.
노란 박스로 빠지는 4가지 — ① 특강 ↔ 특강(택일 수강이라 동시 수강 자체가 없음) ② 클리닉 ↔ 클리닉(유동 운영) ③ 같은 선생님의 수업 ↔ 클리닉(정규반 클리닉 시간이 곧 특강반 수업 시간이라 같은 공간에서 함께 돌아감) ④ 다른 선생님 수업 ↔ 클리닉(클리닉은 다른 요일로 대체 가능).
학교공통 강좌(대상 학교 = 공통)는 미사고·미사강변고·하남고·풍산고에 같이 들어가는 한 개의 수업입니다. 그래서 겹침이 생겨도 학교마다 따로 세지 않고 1건으로 묶여 [고1 전체 (학교공통)]로 표시됩니다. 예전처럼 같은 내용이 4번 반복되면 잘못된 것이니 원장님께 알려주세요.

시간표 보는 법

  • 진한 색 칸 = 수업, 빗금 칸 = 관리(클리닉) 입니다.
  • 수학 블록의 색 배지는 단원입니다 — 공통수학1(파랑)·공통수학2(보라)·대수(자홍)·미적분(빨강)·확률과통계(초록)·기하(청록).
  • 빨간 특강 배지가 붙은 것은 정규가 아니라 특강입니다.
시간표 아래 「2페이지 — 수업 방식·안내」 가 함께 있습니다. 시간만 궁금해하시면 1장, 어떻게 가르치는지 물으시면 2장 다 드리면 됩니다.

4. 수강료를 물어볼 때

💬 이런 상황 — “한 달에 얼마예요?” / “교재비 따로 있어요?” / “컨설팅은 얼마예요?”
  1. 💰 수강료 탭을 누릅니다.
  2. 위쪽에서 청구할 달을 고릅니다. 그 달의 회차로 자동 계산됩니다.
  3. 선생님별로 보려면 선생님 이름을 누릅니다.
항목안내 방법
중등월 수강료입니다. 그 달에 수업이 몇 번이든 금액이 같습니다.
고등회차로 계산됩니다. 화면의 “○월 청구액”이 그 달 금액입니다.
유인물 사용비고등 영어 강좌에만 붙는 9,000원입니다. 학원이 직접 만든 인쇄물(어휘 재테스트지·오답 클리닉지·첨삭 워크시트) 실비이고, 교습비에 포함되어 있습니다.
다른 과목·학년은 화면에서 칸이 잠겨 “해당 없음”으로 나옵니다. 학부모께는 “따로 걷는 돈은 없습니다”라고 안내하세요.
교재비교습비에 포함됩니다. 학원법상 교재비를 따로 받을 수 없어, 수강료+교재비 = 고지 교습비로 교육청에 신고하고 학원에 게시합니다.
구간은 9,000 / 19,000 / 29,000 / 39,000 / 49,000 / 59,000 / 69,000 / 79,000원 8가지뿐입니다. 외부 교재는 학부모가 직접 구매하십니다.
입시 컨설팅수강료 탭 맨 아래 고정 표에 항상 있습니다. 예약제라 월별로 변하지 않습니다.
꼭 기억 — 화면의 금액은 학생 1명 기준입니다. “총 합계”는 인원수를 곱한 금액이 아닙니다. 학부모께는 그 학생 줄의 금액만 말씀하세요.
정확한 결제일·환불 규정은 「학원 사용 설명서」(상담용 자료 ⑦번)에 다 있습니다. 애매하면 그 문서를 드리세요. 결제는 매달 27일 자동, 비대면 카드가 원칙입니다.
