1. 상담하러 학생·학부모가 오셨을 때

💬 이런 상황 — “중2인데 상담 좀 받으러 왔어요.” / 전화로 “자료 좀 받아볼 수 있을까요?”

인쇄해서 드리는 순서

  1. 🖨️ 상담용 자료 탭을 누릅니다.
  2. 학년을 고릅니다. 중등은 중1·중2·중3, 고등은 학교까지 골라야 합니다(미사고1 / 미사강변고1 / 하남고1 / 미사고2 / 미사강변고2 / 고3).
  3. 포함할 항목이 전부 체크되어 있는지 확인합니다. 필요 없는 것만 눌러서 끕니다.
  4. 🖨️ 전체 인쇄 / PDF 저장 을 누르면 인쇄창이 뜹니다. 그대로 인쇄하시면 됩니다.

무엇이 인쇄되나요

문서이런 내용입니다
① 학원 리플렛다올105 × 대치더올 소개. 학원이 어떤 곳인지 한눈에 보여드리는 자료
② 학년별 시간표고른 학년의 주간 시간표. 지금 실제로 열려 있는 수업 그대로
③ 수업 방식 안내과목별로 왜 이렇게 가르치는지, 선생님 원칙, 강좌 내용, 사용 교재
④ 강사 프로필·실적그 학년 담당 선생님 사진·이력·주요 성적 우수자
⑤ 전체 성적 우수자학원 전체 명단 (1등급·만점·대학 합격)
⑥ 입시 컨설팅고등 학년을 골랐을 때만 나옵니다. 프로그램·비용·필요 서류
⑦ 학원 사용 설명서수강료·환불·결제·보강·퇴원 규정. 신입생 학부모 필독
중등을 골랐을 때 입시 컨설팅이 안 나오는 것은 정상입니다. 고등 학년에서만 나오도록 되어 있습니다.
주의 — 학년을 잘못 고르면 다른 학년 시간표가 인쇄됩니다. 인쇄 전에 화면 맨 위 학년이 맞는지 한 번만 더 봐 주세요.

2. 시간표를 물어볼 때

💬 이런 상황 — “중1 영어는 몇 시에 해요?” / “토요일에 무슨 수업 있어요?” / “이 시간에 강의실 비어요?”
질문어디를 보나요
“○학년 시간표 주세요”🎓 학년별 시간표 → 학년 클릭 → 🖨️ PDF/인쇄 또는 🖼️ 이미지저장
문자로 보낼 거면 이미지저장이 편합니다.
“수요일에 뭐 있어요?”
“그 시간 강의실 있어요?”		📅 요일별·강의실 → 요일 클릭. 어느 강의실에서 하는지까지 나옵니다.
“학교별로 뽑아주세요”🎨 시간표 생성 → 학교·학년·과목 조건을 골라 출력

시간표 보는 법

  • 진한 색 칸 = 수업, 빗금 칸 = 관리(클리닉) 입니다.
  • 수학 블록의 색 배지는 단원입니다 — 공통수학1(파랑)·공통수학2(보라)·대수(자홍)·미적분(빨강)·확률과통계(초록)·기하(청록).
  • 빨간 특강 배지가 붙은 것은 정규가 아니라 특강입니다.
시간표 아래 「2페이지 — 수업 방식·안내」 가 함께 있습니다. 시간만 궁금해하시면 1장, 어떻게 가르치는지 물으시면 2장 다 드리면 됩니다.

3. 수강료를 물어볼 때

💬 이런 상황 — “한 달에 얼마예요?” / “교재비 따로 있어요?” / “컨설팅은 얼마예요?”
  1. 💰 수강료 탭을 누릅니다.
  2. 위쪽에서 청구할 달을 고릅니다. 그 달의 회차로 자동 계산됩니다.
  3. 선생님별로 보려면 선생님 이름을 누릅니다.
항목안내 방법
중등월 수강료입니다. 그 달에 수업이 몇 번이든 금액이 같습니다.
고등회차로 계산됩니다. 화면의 “○월 청구액”이 그 달 금액입니다.
교재비수강료와 별도입니다. 학원에서 배부하는 교재는 1만원~5만원이 추가로 청구되고, 외부 교재는 직접 구매하십니다.
입시 컨설팅수강료 탭 맨 아래 고정 표에 항상 있습니다. 예약제라 월별로 변하지 않습니다.
꼭 기억 — 화면의 금액은 학생 1명 기준입니다. “총 합계”는 인원수를 곱한 금액이 아닙니다. 학부모께는 그 학생 줄의 금액만 말씀하세요.
정확한 결제일·환불 규정은 「학원 사용 설명서」(상담용 자료 ⑦번)에 다 있습니다. 애매하면 그 문서를 드리세요. 결제는 매달 27일 자동, 비대면 카드가 원칙입니다.

💬 이런 상황 — 선생님이 “시간 바뀌었어요” / “반 하나 더 열어요” / “그 반 폐강이에요”

새 강좌 추가

  1. ✏️ 시간표·수강료 강좌 수정 및 추가 → ＋ 새 강좌 추가
  2. 맨 위에 빈 줄이 생깁니다. 강사 · 학년 · 과목 · 강좌명을 채웁니다.
  3. ⋯ 상세 를 눌러 시간을 넣습니다. 이게 제일 중요합니다.
  4. 수강료·교재비를 넣으면 끝입니다. 따로 저장하지 않아도 됩니다.

관리·클리닉 수업은 뒤에 “관리” 또는 “클리닉”이라고 적어주세요. 그래야 시간표에 빗금으로 구분되어 나옵니다.

폐강 처리

  1. 🗑️ 강좌 삭제 → 학년 순으로 전체 강좌가 나옵니다.
  2. 지울 강좌 오른쪽 🗑 삭제 를 누르고 확인창에서 확인합니다.
삭제는 되돌릴 수 없습니다. 확인창에 뜨는 선생님 이름과 강좌명을 반드시 읽고 누르세요. 잘못 지웠으면 원장님께 바로 말씀하세요.
지우지 말아야 할 때 — 시간만 바뀐 경우, 잠깐 쉬는 경우는 삭제하지 말고 수정하세요.

5. 등록한 학생에게 다른 과목을 권할 때

💬 이런 상황 — 영어만 다니는 중1 학생에게 국어·수학도 안내하고 싶을 때 / 상담 후 자료를 문자로 보내고 싶을 때
  1. 🔗 과목 안내 페이지 탭을 누릅니다.
  2. 학년을 고릅니다.
  3. 지금 듣고 있는 과목을 체크합니다. → 나머지 과목이 자동으로 안내 대상이 됩니다.
  4. (선택) 학생 이름을 넣으면 페이지에 이름이 들어갑니다.
  5. 📋 링크 복사 → 문자·카톡에 붙여넣어 보냅니다.

이 링크에 뭐가 들어있나요

  • 그 과목이 왜 필요한지 (학부모가 읽는 설명)
  • 담당 선생님 사진·이력·수업 원칙·성적 우수자
  • 강좌 시간·내용·교재
  • 지금 듣는 수업과 시간이 겹치는지 자동으로 표시 (겹치면 빨간 글씨)
  • 주간 시간표 · 자주 묻는 질문 · 전화 버튼
링크는 다시 만들 필요 없습니다. 나중에 강좌가 바뀌면 이미 보낸 링크에도 자동으로 반영됩니다.

7. 자주 하는 실수 — 이것만 조심하세요

1. 학년을 안 바꾸고 인쇄
앞사람 상담 때 골라둔 학년이 그대로 남아 있습니다. 인쇄 전에 학년을 꼭 확인하세요.
2. 수강료를 인원수로 곱해서 말함
화면 금액은 1명 기준입니다. 화면 아래 “합계”는 내부 확인용이라 학부모께 말하지 마세요.
3. 삭제와 수정을 헷갈림
시간이 바뀐 것뿐인데 지우면 안 됩니다. 지우기 = 폐강일 때만 씁니다.
4. 시간을 대충 적음
주3회, 저녁 처럼 적으면 시간표에 아예 안 나옵니다. 반드시 월수금 18:30~20:00 형식으로.
5. 저장 버튼을 찾음
저장 버튼은 없습니다. 자동 저장입니다. 저장됨 ✓ 만 확인하세요.
6. 화면이 안 바뀔 때
다른 사람이 동시에 고치면 잠깐 안 맞을 수 있습니다. ↻ 새로고침 을 누르거나 F5.
7. 선생님께 다른 반 정보를 말하지 않기 — 특히 조심해 주세요
선생님께는 본인 담당 강좌 이야기만 합니다. 아래는 절대 공개하지 않습니다.
· 다른 학년·다른 학교 반의 수강생 수
· 다른 선생님 반의 인원·수강료·정산 금액
· 반별 등록 현황 비교
선생님이 물어보시면 “제가 답변드릴 수 있는 부분이 아니라 원장님께 여쭤보겠습니다” 라고 안내하세요. 운영자 화면에는 전 강좌 정보가 다 보이기 때문에, 선생님 앞에서 운영자 화면을 열어두지 마세요.

8. 상황별 빠른 찾기

학부모·선생님이 이렇게 말하면이렇게 하세요
“상담 왔어요”🖨️ 상담용 자료 → 학년 선택 → 전체 인쇄
“시간표 좀 보내주세요”🎓 학년별 시간표 → 학년 → 이미지저장 → 문자 전송
“얼마예요?”💰 수강료 → 달 선택 → 해당 강좌 줄 (1명 기준)
“교재비도 있어요?”있습니다. 학원 배부 교재 1만~5만원 별도 청구
“컨설팅은요?”💰 수강료 맨 아래 고정 표 (고등만)
“환불 되나요?” “보강 되나요?”학원 사용 설명서 인쇄해서 드리기 (상담용 자료 ⑦)
“다른 과목도 궁금해요”🔗 과목 안내 페이지 → 링크 복사 → 문자 전송
선생님 “시간 바뀌었어요”✏️ 시간표·수강료 강좌 수정 및 추가 에서 시간 수정
선생님 “반 하나 더 열어요”같은 탭 → ＋ 새 강좌 추가
선생님 “그 반 폐강이에요”🗑️ 강좌 삭제 (되돌릴 수 없음, 확인 필수)
“오늘 무슨 수업 있어요?”📅 요일별·강의실 → 요일 클릭
“어느 강의실이에요?”📅 요일별·강의실 에 강의실까지 표시됨
